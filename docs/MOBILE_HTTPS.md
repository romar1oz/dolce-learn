# Доступ с телефона по HTTPS в локальной сети

PWA (установка на экран, Service Worker, офлайн-режим) работает только по HTTPS. Для пилота в локальной сети
Dolce Learn использует собственный локальный центр сертификации (CA): его сертификат один раз устанавливается
на телефон, после чего телефон доверяет серверу без предупреждений.

## 1. Запуск сервера (на компьютере)

```bash
./scripts/dev.sh --https
```

Скрипт при первом запуске (и при смене IP-адреса) вызывает `./scripts/https-setup.sh`, который:
- создаёт локальный CA в `.certs/ca.crt` (закрытый ключ `.certs/ca.key` не покидает компьютер и не попадает в git);
- выпускает сертификат сервера для `localhost`, `<имя-компьютера>.local` и всех текущих IP-адресов;
- печатает адреса для телефона и SHA-256 отпечаток CA.

Адреса на этом компьютере (на момент настройки):

| Что | Адрес |
|---|---|
| Приложение (HTTPS) | **https://172.16.1.253:4443** |
| То же по имени (удобно для iPhone) | https://MacBook-Air-roma.local:4443 |
| Сертификат CA (скачать на телефон) | **http://172.16.1.253:4173/dolce-local-ca.crt** |

Телефон и компьютер должны быть в одной Wi-Fi сети. Если IP компьютера изменится, перезапустите `./scripts/dev.sh --https` —
сертификат сервера перевыпустится автоматически, переустанавливать CA на телефоне не нужно.

## 2. Установка сертификата на телефон (один раз)

Перед установкой сверьте отпечаток SHA-256 с тем, что напечатал `https-setup.sh`.

### Android
1. Откройте в Chrome `http://172.16.1.253:4173/dolce-local-ca.crt` — файл скачается.
2. Настройки → Безопасность (или «Безопасность и конфиденциальность») → Шифрование и учётные данные →
   Установить сертификат → **Сертификат ЦС** → выберите `dolce-local-ca.crt` → подтвердите.
3. Откройте **https://172.16.1.253:4443** — замка без предупреждения. Меню ⋮ → «Установить приложение».

### iPhone / iPad
1. Откройте в **Safari** `http://172.16.1.253:4173/dolce-local-ca.crt` → «Разрешить» загрузку профиля.
2. Настройки → «Профиль загружен» → Установить (введите код телефона).
3. Настройки → Основные → Об этом устройстве → **Доверие сертификатам** → включите «Dolce Learn Local CA».
4. Откройте **https://MacBook-Air-roma.local:4443** (или по IP) → «Поделиться» → «На экран «Домой»».

## 3. Проверка офлайн-режима на телефоне

1. Войдите как `employee@dolce.local`, откройте курс → «Скачать для офлайн-доступа» → «Доступен офлайн».
2. Включите авиарежим, откройте Dolce Learn с иконки → баннер «Офлайн-режим», курс, видео, PDF и тест доступны.
3. Выключите авиарежим → индикатор в шапке покажет синхронизацию, результат теста появится автоматически.

## Безопасность

- Локальный CA предназначен только для пилота/разработки. Сертификат сервера ограничен 825 днями, CA — 5 годами,
  у CA `pathlen:0`, ключи — только на этом компьютере (`.certs/`, права 700/600).
- После пилота удалите сертификат с телефонов (Android: Настройки → Учётные данные пользователя; iOS: Основные → VPN
  и управление устройством) и используйте корпоративный сертификат (см. `DEPLOYMENT.md`).
- Пересоздать CA: `./scripts/https-setup.sh --new-ca` (потребуется переустановка на телефонах).

## Если не открывается

- Проверьте, что телефон в той же сети и адрес пингуется; гостевые Wi-Fi часто изолируют устройства друг от друга.
- Брандмауэр macOS (Системные настройки → Сеть → Брандмауэр) должен разрешать входящие подключения для `node`
  (сейчас брандмауэр выключен).
- Android может не разрешать имена `*.local` — используйте IP-адрес.
